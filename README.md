## 🌟 About Tech Indro

**Tech Indro** is a modern, next-generation EdTech platform and learning ecosystem designed to take aspiring technologists, developers, and researchers from **zero to one**. 

With an intuitive **Web Platform** and a slick **React Native / Expo Mobile App**, Tech Indro bridges the gap between academic theory and high-impact industrial skills in **AI, Cybersecurity, Robotics, and Full-Stack Engineering** — requiring **no prior coding background or expensive laptops**.

## 📱 Mobile App (React Native & Expo)

The **Tech Indro Mobile App** delivers a native, buttery-smooth learning experience:

- **Universal Navigation**: Fast tab routing with clean access to `Programs`, `TSOC`, `IndroLabs`, `Features`, and `Test Series`.
- **Theme Support**: Seamless dark/light adaptation across all screens.
- **Doubt Assistant**: Instant text & voice query resolution on-the-go.
- **Offline Notes & Bookmarks**: Save essential revision cards and study notes.

### Run the Mobile App:
```bash
# Navigate to app directory
cd tech-indro-app

# Install dependencies
npm install

# Launch Expo development server
npx expo start
```
*Press `a` for Android emulator, `i` for iOS simulator, or `w` for Expo Web.*

## 🌐 Web Platform & Server

The **Tech Indro Web Platform** is optimized for high-performance, SEO, and enterprise security:

- **Zero-Build Vanilla PWA**: Instant load times and lightweight footprint.
- **Enterprise WAF & Anti-Crash Hardening**:
  - `helmet` security headers & CSP protection.
  - Granular sliding-window rate limiters on Authentication, AI Chat, and Code Compiler.
  - Safe execution sandboxing to prevent malicious infinite loops or memory leaks.
  - Unhandled rejection & uncaught exception safety handlers for 100% uptime.

### Run the Web Platform:
```bash
# Navigate to website directory
cd tech-indro-official

# Install dependencies
npm install

# Start local server
npm start
```
*Server boots up on `http://localhost:5000`.*

## 🔌 REST API Reference & Endpoints

Tech Indro exposes a fast, hardened JSON REST API powering both the Web Platform and the React Native Mobile App.

- **Production API Base**: `https://tech-indro-official.vercel.app/api`
- **Local Development Base**: `http://localhost:5000/api`

### 📡 Core API Endpoints

| Method | Endpoint | Description | Live Endpoint Link |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/courses` | Returns all 18+ flagship programs, syllabus, fees & ratings | [🔗 View JSON](https://tech-indro-official.vercel.app/api/courses) |
| `GET` | `/api/courses/:id` | Detailed curriculum & modules for a specific course | [🔗 View Sample](https://tech-indro-official.vercel.app/api/courses/ai-mastery) |
| `GET` | `/api/shikshak-courses` | Beginner & kids coding foundation programs | [🔗 View JSON](https://tech-indro-official.vercel.app/api/shikshak-courses) |
| `GET` | `/api/ai-tools` | Directory of 50+ curated AI developer tools & resources | [🔗 View JSON](https://tech-indro-official.vercel.app/api/ai-tools) |
| `GET` | `/api/analytics` | Real-time platform traffic & visitor analytics | [🔗 View JSON](https://tech-indro-official.vercel.app/api/analytics) |
